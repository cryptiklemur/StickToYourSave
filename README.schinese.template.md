# Stick To Your Save

把 RimWorld 锁在你正在玩的那个殖民地上。

你知道那个循环。局面变糟，袭击打崩了，然后忽然觉得重开一个部落开局听起来挺香。这个模组把那条退路堵死。

## 它做什么

殖民地被锁定期间：

- 读取界面只接受这个殖民地的存档。自动存档、手动存档都可以，其他一律拒绝。
- 开新殖民地会被阻止。

锁定会绑在你保存或读取的那个殖民地上。老老实实玩手里这个档。

## 怎么解除

以下情况锁定会自动解除：

- 通关（任何会放演职员表的结局）
- 殖民地团灭（游戏结束，全员阵亡）
- 删掉这个殖民地的存档文件

真的得提前退出？主菜单上有一个 "Clear save lock" 按钮。它会问你三次，而且一次比一次更替你感到失望。在模组列表里关掉它同样会问三次。

## 需求

- RimWorld 1.6
- [Concord](https://steamcommunity.com/sharedfiles/filedetails/?id=3758333473)

可以直接加进正在进行的存档。下次保存或读取时，锁定会绑到你当前的殖民地。中途移除也没问题，只要你能过得了那几次确认。
