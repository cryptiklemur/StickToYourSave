# Stick To Your Save

Locks RimWorld to the colony you're already playing.

You know the loop. Things get hard, the raid goes sideways, and suddenly a fresh tribal start sounds real nice. This mod takes the option away.

## What it does

While a colony is locked in:

- The load screen only accepts saves from that colony. Autosaves, manual saves, all of them work. Anything else gets refused.
- Starting a new colony is blocked.

The lock binds to whatever colony you save or load. Play the save you have.

## Getting out

The lock clears on its own when you:

- Win the game (any ending that rolls credits)
- Lose the colony (game over, everyone's dead)
- Delete the colony's save files

Really need out early? There's a "Clear save lock" button on the main menu. It asks three times, and it gets more disappointed in you with each one. Disabling the mod in the mod list asks three times too.

## Requirements

- RimWorld 1.6
- [Concord](https://steamcommunity.com/sharedfiles/filedetails/?id=3758333473)

Safe to add to an existing game. The lock binds to your current colony the next time you save or load. Removing it mid-run is fine too, once you make it past the confirmations.
